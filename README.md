
# Python Programming

Учебные лабораторные работы и задания по программированию на Python.

## Содержание

- `lb/` — базовые упражнения.
- `lb2/`, `lb4/` — лабораторные работы.
- `lb9/`, `lb10/`, `lb11/`, `lb12/` — лабораторные работы по последующим темам.
- `РГЗ/` — расчётно-графическое задание с графическим интерфейсом на PySimpleGUI.

## Запуск

Для запуска отдельной программы:

```bash
python3 lb2/1.py
```

Выбери нужный файл в соответствующей папке.

Некоторые задания используют дополнительные текстовые файлы и локальные пути. Перед запуском таких программ необходимо настроить пути к входным данным.

## Технологии

- Python 3
- PySimpleGUI (для РГЗ)
